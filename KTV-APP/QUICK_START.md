# Quick Start Guide

## Installation & Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Navigate to `http://localhost:3000`

## First Steps

1. **Login:** Click "Login" in the header and use any email/password (demo mode)

2. **Browse Songs:** Navigate to "Song Library" to see available songs

3. **Play a Song:** Click on any song card to start playing

4. **View Lyrics:** When a song is playing, lyrics will appear below the song grid

5. **Add to Favorites:** Click the heart icon on any song

6. **Create Playlist:** 
   - Go to "Profile" 
   - Click "Playlists" tab
   - Click "Create New Playlist"
   - Select songs and save

7. **Rate Songs:** When a song is playing, scroll down to see the rating component

8. **Upload Song:** Click "Upload Song" in the Song Library page

## Features Overview

- **Home Page:** Trending songs and quick access
- **Song Library:** Search, filter, and browse all songs
- **Profile:** View favorites and manage playlists
- **Settings:** Customize theme, audio, and preferences
- **Audio Player:** Fixed bottom player with full controls

## Tips

- Use the search bar to find specific songs
- Filter by genre to narrow down results
- Toggle dark mode in Settings
- Adjust volume and mic levels in the audio player
- Create multiple playlists for different moods

Enjoy singing! 🎤
